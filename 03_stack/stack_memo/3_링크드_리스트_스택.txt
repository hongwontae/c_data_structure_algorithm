1. 링크드 리스트 스택
    1-1. 인덱스를 통한 접근이 불가 -> 노드들은 자신의 위에 위치하는 노드에 대한 포인터가 필요합니다.


2. 링크드 리스트 스택 구조체 + 노드 구조체
    2-1. 노드 구조체
        => char * data / tag_node * next_node;
        => 이름 데이터와 노드의 다음 노드를 가리키는 포인터가 정의되었습니다.
    
    2-2. 스택 구조체
        => node * list / node * top
        => list는 노드의 첫 번째 위치 / top은 스택 포인터를 의미합니다.


3. 링크드 리스트 스택 생성
    3-1. main의 지역변수 Stack 구조체 포인터에 동적할당된 주소를 주기 위해 이중 포인터를 받습니다.
    3-2. *stack으로 접근해서 malloc을 사용해 동적할당합니다. -> 스택 구조체 초기화
    3-3. *stack->list / *stack->top은 NULL로 초기화합니다.


4. 링크드 리스트 노드 생성
    4-1. 노드를 생성하고 그 노드의 주소를 return하는 함수입니다.
        => 스택 구조체에 연결하는 함수는 따로 존재
    4-2. malloc을 통해 newnode를 생성하고 node 내부의 char * data도 동적할당합니다.
        => strcpy로 값을 넣습니다.
    4-3. 그리고 다음 노드에 대한 주소는 NULL로 초기화하고 return 합니다.


5. 링크드 리스트 노드 push
    5-1. 만약 Stack의 List가 NULL이라면 스택 구조체 연결이 한 번도 안되었다는 의미입니다.
        => 이 경우 Stack->List = new_node/ Stack->top = new_node로 처리합니다.
        => 여기서 List는 Stack의 가장 밑바닥에 존재하는 노드 / top은 stack_pointer입니다.
    5-2. 만약 Stack List가 존재한다면 적어도 하나는 존재한다는 의미이고 위로 쌓아야 합니다.
        => 그렇다면 기존의 top의 노드의 next_node를 new_node로 설정하고 top을 new_node로 설정합니다.


6. 스택 개수 함수
    => new_node의 next_node는 null입니다. 즉, top의 next_node는 NULL을 가리키고 있습니다.
    => 그리고 Stack 구조체의 List는 밑바닥입니다.
    => List부터 시작해서 NULL까지 가면 개수를 알 수 있습니다.


7. 스택 포인터 확인 함수
    => Stack->Top을 통해 알 수 있습니다.


8. 스택 is_empty 함수
    => Stack->List가 NULL이라면 아무런 노드가 없다는걸 의미합니다.
    => return Stack->List == NULL;


9. 스택 pop 함수
    => 3가지 상황을 고려해야 합니다.
    => Stack->List == NULL / Stack->List == Stack->Top / Stack->List != Stack->Top
    => List가 Null이라면 노드가 한 번도 들어오지 않았던 것입니다. -> 바로 return NULL;
    => Stack->List와 Stack->Top이 같다면 한 번 들어온 것입니다. -> Stack->List = NULL, Stack->Top = NULL
    => Stack->List와 Stack->Top이 다르다면
    => Stack->List부터 올라갑니다. -> Top 전까지 -> 싱글 링크드라 List부터 올라가야 알 수 있습니다.
    => 그리고 Top 전을 Stack->Top으로 / Stack->Top->next_node = NULL로 처리합니다.
    => 첫 번쨰 상황을 제외하고 return Top_Node를 해야합니다. -> free()처리하는 함수에 줘야합니다.


10. 노드 free() 함수
    => top_node를 받아서 node->data먼저 초기화하고 node를 초기화합니다.


11. 스택 구조체 free() 함수
    => while문으로 초기화되지 않은 node가 있는지 확인합니다.
    => 있다면 초기화합니다.
    => 마지막에 스택 구조체를 free() 합니다.
