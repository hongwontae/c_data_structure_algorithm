1. 링크드 리스트 스택
    1-1. 인덱스를 통한 접근이 불가 -> 노드들은 자신의 위에 위치하는 노드에 대한 포인터가 필요합니다.


2. 링크드 리스트 스택 구조체 + 노드 구조체
    2-1. 노드 구조체
        => char * data / tag_node * next_node;
        => 이름 데이터와 노드의 다음 노드를 가리키는 포인터가 정의되었습니다.
    
    2-2. 스택 구조체
        => node * list / node * top
        => list는 노드의 첫 번째 위치 / top은 스택 포인터를 의미합니다.
