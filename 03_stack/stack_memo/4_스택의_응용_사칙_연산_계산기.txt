1. 사칙 연산 계산기
    1-1. 알고리즘
        => 원본 수식을 컴퓨터가 풀기 쉬운 형식으로 변환
        => 변환된 수식을 계산


2. 수식의 중위 표기법과 후위 표기법
    2-1. 중위 표기법 -> 연산자가 피연산자 가운데 위치합니다.
    2-2. 후위 표기법 -> 연산자가 피연산자 뒤에 위치합니다.
        => 후위 표기법은 피연산자를 읽다가 연산자를 만나면 가장 마지막에 나온 연산자 두 개를 연산자로 계산하면 됩니다.
    2-3. 차이
        => 1 + 3        | 1 3 +
        => 23 / 7 + 12  | 23 7 / 12 +
        => 1 - 3 * 2    | 1 3 2 * -
    2-4. 후위 표기법 해석
        => 5 2 * 8 4 / +
        => 5*2 (10 8 4 / +)
        => 8/4 (10 2 +)
        => 12


3. 후위 표기법을 계산하는 알고리즘 (feat. stack)
    3-1. 132*-에서 숫자 스택를 둡니다.
    3-2. 숫자 스택은 1 3 2 순으로 들어가갑니다.
    3-3. *를 만나면 숫자 스택의 stack_pointer를 통해 2개를 꺼냅니다.
    3-4. 그리고 2개와 * 연산을 하고 stack에 넣습니다.
    3-5. -를 만나서 stack_pointer에서 피연산자 두 개를 꺼내고 연산을 하고 stack에 넣습니다.
        => 이렇게 스택에는 최종 결과만 남습니다.


4. 중위 표기법을 후위 표기법으로 바꾸는 알고리즘
    4-1. 입력 받은 중위 표기식에서 토큰을 읽는다.

    4-2. 토큰이 피연산자라면 토큰을 결과에 출력한다.

    4-3. 토큰이 연산자(괄호 포함)라면 스택의 최상위 노드에 담긴 연산자가 토큰보다 
        우선순위가 높은지 검사한다(검사가 끝나면 스택에는 최상위 노드보다 우선순위가 높은 연산자가 남아 있지 않게 된다).

    4-4. 검사 결과가 참이면(토큰이 최상위 노드의 연산자보다 낮으면) 최상위 노드를 스택에서 꺼내 결과에 출력하며,
        이 검사 작업을 반복해서 수행하되 그 결과가 거짓이거나 스택이 비면 작업을 중단한다.

    4-5. 검사 작업이 끝난 후에는 토큰을 스택에 삽입한다.

    4-6. 토큰이 오른쪽 괄호 )면 최상위 노드에 왼쪽 괄호 (가 올 때까지 스택에 제거 연산을 수행하고 
        제거한 노드에 담긴 연산자를 출력한다. 왼쪽 괄호를 만나면 제거만 하고 출력하지는 않는다.

    4-7. 중위 표기식에 더 읽을 것이 없다면 반복을 종료하고 더 읽을 것이 있다면 단계 ①부터 다시 반복한다.
