1. 배열 스택
    1-1. 각 노드를 동적으로 생성하는게 아니라 스택 생성 초기에 사용자가 부여한 만큼 생성하는 흐름으로 구현합니다.
    1-2. 배열 기반 스택은 세 가지 필드가 필요합니다.
        => 용량, 최상위 노드의 위치, 노드 배열

2. 배열 기반 스택과 스택의 노드 표현
    2-1. 스택 구조체와 스택 구조체에 들어가는 데이터 구조체를 선언합니다.
    2-2. 스택 구조체는 총 개수, stack_pointer의 인덱스, 스택에 존재하는 노드의 첫 주소

2. 스택 노드 생성/소멸 연산
    2-1. stack 구조체 + Stack 노드 생성 연산
        => 이중 포인터 ** Stack을 받고 main 지역 변수 stack 값에 동적할당을 시작합니다.
        => capcity만큼 Nodes를 생성하고 첫 주소를 stack 구조체에 전달합니다.
        => capcity를 * stack에 전달 / *stack->top = -1를 할당합니다.
        => 인덱스 접근이고 실질적으로 데이터가 들어오지 않았습니다. -> 데이터가 들어오는 push 연산시 +1 -> 0접근 가능
    
    2-2. Stack 구조체 + Stack 노드 소멸 연산
        => *Stack를 받아서 스택 구조체와 노드들을 초기화합니다.


3. 스택 노드 삽입 연산 / 제거 연산
    3-1. 삽입 연산
        => stack 구조체의 top++
        => stack->nodes[stack->top].data = data;
        => 스택 포인터 공간에 데이터를 추가합니다.
    
    3-2. 제거 연산
        => int location = stack->top--; / 후위 연산자를 통해 location의 스택 포인터를 연산 하기 전이 들어갑니다.
        => return stack->nodes[stack->top].data; -> 스택 포인터가 내려가면서 없어졌다고 판단합니다.
