1. 링크드 리스트
    1-1. 링크드 리스트는 노드를 연결해서 만든 리스트라고 해서 붙여진 이름입니다.
    1-2. 링크드 리스트의 노드는 데이터를 보관하는 필드, 다음 노드와 연결 고리 역할을 하는 포인터로 이루어집니다.


2. 링크드 리스트의 노드 표현
    2-1. 링크드 리스트 구조체 선언과 정의
        typedef strcut Node {
            int data;
            strcut node * next_node;
        } Node
        Node node_1 = {4, &node2};
        => 노드에 데이터와 구조체의 주소를 저장할 수 있는 형태로 만듭니다.


3. 링크드 리스트 주요 연산
    3-1. 자료구조를 구축하기 위한 연산과 자료구조에 저장된 데이터를 활용하기 위한 연산
        => 노드 생성/소멸, 노드 추가, 노드 탐색, 노드 삭제, 노드 삽입
    
    3-2. 노드 생성/소멸 연산
        1. 노드를 생성할 떄는 malloc를 통해 heap 영역에 메모리 공간을 확보합니다.
        2. 그리고 구조체 포인터에서 -> 접근자를 통해 값을 초기화합니다.
        3. 그리고 생성된 구조체 포인터를 return 합니다.

        4. 삭제할 떄는 함수에서 포인터를 받아서 free()의 인자에 넣습니다.
    
    3-3. 노드 추가 연산
        => 노드 추가는 링크드 리스트의 테일 노드 뒤에 새로운 노드를 연결하는 연산입니다.
