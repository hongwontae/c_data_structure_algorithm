1. 구조체 포인터 변수 자체가 다른 주소를 가리키도록 변경하고 싶을 떄 이중 포인터를 사용합니다.


2. int a = 10; int p = &a; add(p, 10);
    => 만약 add에서 p = address로 변경했다면 main의 p에 영향을 받을까?
    => 영향을 받지 않습니다. p의 값을 복사해서 전달할 뿐입니다.
    => add 함수내의 p는 &a를 담고 있는 다른 공간입니다. 여기서 p = NULL로 변경
    => main내의 p에 영향을 주지못합니다.
    => 이 떄 p를 변경하고 싶다면 이중포인터를 사용해서 역참조를 해야합니다.
    => 역참조를 해야 main 내의 p의 공간을 target 합니다.
    => 역참조가 중요합니다.!!
