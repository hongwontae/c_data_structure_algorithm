1 자료 구조
    1-1. 컴퓨터가 데이터를 효율적으로 다룰 수 있게 도와주는 데이터 보관 방법과 데이터에 관한 연산의 총체입니다.
        => 데이터 보관 방법 : 데이터를 메모리에 어떤 형태로 저장할 것인가?
        => 데이터 연산 : 저장된 데이터를 어떻게 읽고, 추가하고 삭제하고 탐색하고 수정할 것인가?

    1-2. int 또한 자료구조입니다. -> 32bit 메모리 공간안에 데이터, 첫 비트를 부호 표현에 사용, 연산 가능한 데이터..
        => int 자료형 데이터는 +, -, *, >>.. 연산 가능

    1-3. 자료구조는 단순 자료구조와 복합 자료구조로 나뉩니다. (단순 자료구조 -> int, char..)
    1-4. 복합 자료구조는 선형 자료구조와 비선형 자료구조로 나뉩니다.
        => 선형 자료구조는 배열, 링크드 리스트, 스택 큐..
        => 비선형 자료구조는 트리, 그래프..
    
    1-5. ADT (Abstract Data Types)
        => 사용자가 이용할 수 있는 연산과 그 동작 규칙을 정의하고 내부 구현은 별도로 다룬다는 의미입니다.
        => 리스트라는 ADT를 싱글 링크드 리스트 || 더블 링크드 리스트 || 환형 링크드 리스트로 구현할 수 있습니다.
