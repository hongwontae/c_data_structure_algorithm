2. C 언어로 메모리 다루는 방법

    2-1. 포인터
        => int a = 10; int * p = &a;
        => 자료형 * 변수 = 주소;
        => 포인터 연산은 sizeof(*p) 만큼 이동합니다. -> 즉, p[n]의 값의 타입만큼 이동
    
    2-2. 구조체
        => 다른 데이터 형식을 조합해서 만드는 사용자 정의 타입입니다.
        => 구조체 변수를 정의 했다면 멤버 접근자 .으로 접근해서 값을 가져오거나 수정할 수 있습니다.
        => 포인터 멤버 접근자는 -> 입니다.
        => 구조체 변수를 정의할 떄 struct 키워드를 제외하고 싶다면 구조체 선언에서 typedef를 사용하면 됩니다.
    
    2-3. 메모리 레이아웃 복습
        => 실행 파일 실행 -> 프로세스 -> 가상 주소 공간 배치 -> 메모리에 텍스트, 데이터, 힙, 스택 영역
        => 텍스트는 명령어, 데이터는 전역 변수나 정적 변수
        => main 함수에 int 자료형 a, b, c 3개 정의 -> 호출 -> a, b, c로 쌓이고 c, b, a 메모리 초기화
        => 스택 영역은 자동으로 해제되고 FIFO입니다.

        => 힙 영역은 프로그래머가 직접 메모리를 관리하는 메모리 영역입니다.
        => malloc, calloc을 사용해서 메모리 공간을 할당받고 free()로 해제합니다.
